# KaloNexus

Klientowy mod Minecraft (Fabric) z systemem waypointów: podgląd przez ściany,
beacony dalekich markerów, konfigurowalny HUD, paczki waypointów z serwera
i publikacja własnych punktów (WebSocket).

Tutejsze **Releases** zawierają wyłącznie gotowe pliki `.jar` — kod źródłowy
jest prywatny.

## Instalacja

1. Zainstaluj **Fabric Loader** (wymagana wersja `>=0.19.5`).
2. Wrzuć pobrany plik `KaloNexus <wersja>+<minecraft>.jar` do folderu `mods`.
3. Zainstaluj **Fabric API** (taka sama wersja Minecrafta).

## Wersje pliku

Nazwa pliku ma format `KaloNexus <wersja moda>+<wersja Minecrafta>.jar`,
np. `KaloNexus 0.1+26.3` = wersja moda **0.1**, Minecraft **26.3**.

## Wymagania

| Wymaganie | Wersja |
|---|---|
| Minecraft | `~26.3` |
| Fabric Loader | `>=0.19.5` |
| Fabric API | dowolna dla 26.3 |
| Java | `>=25` |
